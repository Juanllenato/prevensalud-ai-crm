◆ Contextual AI Assistant

RAG over operational data — grounded, bounded, PII-free

  • →Intent → modules. A keyword router maps each question to only the relevant data modules; a "sales" question never touches seven other tables.
  • →One query per module. SQL FILTER aggregates return today + month-to-date in a single round-trip.
  • →Aggregates, never rows. The LLM receives counts, sums, group-bys and a staff roster with month-over-month trend — never a name, phone, DNI or medical record.
  • →Per-user policy. ConfiguracionAI gates by access level, enabled modules and sensitive flags (collections, payroll).
  • →Tenant-scoped. Always filtered to the user's branch(es).

◆ OCR Invoice Processing

Snap a photo on WhatsApp → an approvable expense

Capturing data where it happens, with a human in the loop and a cost-first engine strategy.

Webhook + verification

Twilio HMAC-SHA1 signature verified (fail-closed); sender matched to a user; role checked (ADMIN/HOSTESS).

Instant response, async work

The webhook returns TwiML 200 immediately and enqueues a Celery task — OCR latency never blocks the reply.

Cost-first multi-engine OCR

Free local Tesseract by default → Google Cloud Vision / Claude Haiku Vision opt-in for hard images. Pillow pre-processing boosts accuracy.

Extract + persist

Amount, date, vendor, reference (regex fallbacks) → validated → Egreso in PENDIENTE_CONFIRMACION with raw OCR JSON kept for audit.

Human-in-the-loop confirmation

Reply SI to approve, NO to reject, or CORREGIR monto=125000 to fix a whitelisted field — no re-upload.

◆ Backend Architecture

A modular monolith with strict layer boundaries

Thin routers, pure-logic services, an isolated integrations layer, and a tenant-aware data core — the boundaries that keep the commission engine testable and the integrations mockable.

🌐

api/v1

~33 routers: validation (Pydantic), authz (require_roles), orchestration.

🧩

services

Pure business logic — commission engine, manifest, PDF builder. No HTTP concerns.

🔌

integrations

The only place external APIs are called: LLM, OCR/Vision, WhatsApp — with timeouts & retries.

🧱

core

Security (JWT/RBAC/Fernet), database (RLS context), config (fail-fast), cache.

◆ Scalability Considerations

Don't do expensive things on the hot path

⚡

Async everywhere

FastAPI + SQLAlchemy async + asyncpg for I/O-bound throughput; stateless JWT for horizontal scale.

🎯

Targeted retrieval

1–3 aggregate queries per AI question instead of full scans.

🗂️

Materialized view

mv_manifiesto_diario (5-min refresh) serves the hottest reads in sub-500 ms.

🧵

Offload CPU work

PDF render in a threadpool; OCR in Celery workers that scale independently of the API.

🧮

Composite indexes

(sucursal_id, fecha_venta), (sucursal_id, estado) on the hottest query paths.

🌎

Distributed limits

Redis-backed rate limiting holds across horizontally-scaled API instances.

◆ Key Engineering Challenges

Real bugs, real fixes

Rate limits that silently didn't fire

Two stacked @limiter.limit decorators don't compose. Fix: single-decorator "8/minute;40/hour" syntax, verified with parallel request bursts.

FastAPI route shadowing

A dynamic /{id} route captured /citas/disponibilidad and parsed the literal as a UUID (422). Fix: order specific routes before parameterized ones.

Hard-reload logout race

A child layout's auth guard ran before the provider rehydrated from localStorage. Fix: gate on !isLoading && !isAuthenticated.

Keeping the model honest

The assistant said "no data" when the truth was "zero advisors in that branch." Fix: add a per-branch summary (incl. empty branches) + rewrite the prompt to separate "no records" from "no access."

pgBouncer + migrations

The pooler rejects CREATE INDEX CONCURRENTLY. Fix: plain CREATE INDEX IF NOT EXISTS + NullPool.

Tenant-switch session drop

Switching branches logged users out. Fix: add X-Sucursal-Id to CORS allow_headers + resolve the hydration race.
